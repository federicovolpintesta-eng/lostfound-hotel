> **Sistema Integral y Modular de Gestión de Objetos Perdidos con Supabase.**

Este sistema reemplaza las planillas manuales tradicionales por un ecosistema digital avanzado con persistencia de datos, notificaciones en tiempo real y automatización de documentos legales de entrega. Diseñado para optimizar la operativa de Los Pinos Resort & Spa Termal.

## ✨ Características Principales
- **Diseño Interactivo**: Interfaz moderna con *Glassmorphism* para una experiencia fluida y visualmente atractiva.
- **Sincronización en Tiempo Real**: Construido utilizando PostgreSQL Channels vía Supabase, permitiendo que cualquier cambio se refleje instantáneamente en todos los clientes conectados.
- **Automatización de Actas Legales**: Generación y descarga automática de actas de entrega en PDF para firmas.
- **Exportación de Datos**: Soporte para descargas y reportes en formato Excel (XLSX).
- **Etiquetas Inteligentes**: Generador dinámico de etiquetas físicas con código QR mediante QRious para un rastreo preciso del inventario.

## 🛠️ Stack Tecnológico
- **Frontend**: HTML5, Vanilla CSS (Glassmorphism), JavaScript (ES Modules).
- **Backend & Base de Datos**: Supabase DB, Supabase Auth.
- **Librerías Adicionales**: Chart.js (Analíticas), jsPDF (Generación de Documentos), XLSX (Exportación), QRious (Códigos QR), ImgBB API (Alojamiento de imágenes).

## 🚀 Uso e Instalación
1. Clonar el repositorio.
2. Configurar las credenciales de Supabase en `supabase.js` o tus variables de entorno correspondientes.
3. Abrir `index.html` en tu navegador o servidor local.
